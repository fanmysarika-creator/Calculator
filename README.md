# CALCULATOR

Рабочий калькулятор. Кнопка **Setting → Скрытые приложения** (нужен пароль) открывает список ваших приложений, которые запускаются только оттуда.

## Как собрать APK с телефона (GitHub)

1. Создайте репозиторий на github.com.
2. Загрузите файлы с сохранением папок: `package.json`, `capacitor.config.json`, `www/index.html`, `native/MainActivity.java`, `native/AppsPlugin.java`.
3. Файл сборки: Add file → Create new file → в имени напишите `.github/workflows/build.yml` и вставьте содержимое файла `build.yml`.
4. Откройте вкладку **Actions** → дождитесь зелёной галочки (≈5–8 минут).
5. Откройте последний запуск → внизу **Artifacts → calculator-apk** → скачайте, распакуйте zip, установите `app-debug.apk`.

## Использование

- Первый вход в Setting → Скрытые приложения: создайте пароль (PIN или буквы).
- Если пароль только из цифр: введите его на калькуляторе и нажмите `=` — сразу откроются скрытые приложения.
- «+ Добавить» — выбрать приложения; «Открыть» — запустить.

## Важно

Android не позволяет обычному приложению скрыть иконки других приложений. Иконки остаются на телефоне, пока вы не уберёте их сами:
**Настройки → Главный экран → Скрыть приложения на главном экране и экране приложений** (Samsung One UI) — отметьте нужные приложения. Тогда открывать их можно будет только через CALCULATOR.
